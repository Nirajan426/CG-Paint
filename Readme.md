# CG-Paint

A small Python project with two fun graphics apps:

- `main.py`: A PyQt6 paint app with classic computer-graphics tools and algorithms.
- `Acroll.py`: A 2-player Paper.io-style area control game built with Pygame.

## Run

Install dependencies:

```bash
pip install PyQt6 pygame
```

Start the paint app:

```bash
python main.py
```

Start the area-control game:

```bash
python Acroll.py
```

## Controls (Acroll)

- Player 1: `W A S D`
- Player 2: `Arrow Keys`
- Restart after game over: `Space`
